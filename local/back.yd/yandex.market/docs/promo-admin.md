# Администрирование выгрузки Промо

Раздел «Промо» создан для управления выгрузкой тегов `<promo>` в файлы «Профилей выгрузки».

Поддерживаемые виды акций:
1. Скидка по промокоду https://yandex.ru/support/partnermarket/elements/promos.html ;
2. Специальная цена в определенный период https://yandex.ru/support/partnermarket/elements/promo-flash.html ;
3. При покупке N товаров M таких же товаров бесплатно https://yandex.ru/support/partnermarket/elements/promo-n-plus-m.html ;
4. Подарок на выбор https://yandex.ru/support/partnermarket/elements/promo-gift.html ;
5. Скидка модуля «Интернет-магазин»;
6. Скидка модуля «Торговый каталог» (доступна только до переноса скидок в модуль «Интернет-магазин»).

## Форма редактирования Промо

Административный интерфейс для создания и редактирования «Промо».

### Шаг «Общие настройки»

На даннам шаге вам необходимо выбрать «Вид акции» и заполнить общие поля.

Список полей:
1. Активность - выгружать ли элемент;
2. Название - внутреннее название акции, не выгружается;
3. Вид акции - правило, по которому будет сформирован тег `<promo>`;
4. Инфоблок подарков - инфоблок, элементы которого будет выгружены в качестве подарков по акции. Доступно только для вида акции «Подарок на выбор»;
5. Ссылка на описание акции на сайте магазин - относительный или абсолютный url-адрес страницы, которая содержит описание акции;
6. Выгружать для всех профилей - выгружать ли элемент во все файлы «Профилей выгрузки»;
7. Выгружать только для профилей - возможность ограничить набор «Профилей выгрузки», в которые необходимо выполнить выгрузку акции;
8. Краткое описание - описание акции, будет выгружено в тег `<description>`. Максимальная длина — 500 символов.

### Шаг «Правила скидки»

На данном шаге вам необходимо заполнить условия акции. Список полей зависит от значения поля «Вид акции», выбранного на шаге «Общие настройки».

Базовые поля акции:
1. Дата и время начала - дата, будет выгружена в тег `<start-date>`;
2. Дата и время завершения - дата, будет выгружена в тег `<end-date>`;
3. Товары по акции - наборы групп товаров и торговых предложений по акции, объединенных по инфоблокам. Примечания:
    - Результат выгрузки - тег `<product>` для каждого предложения акции;
    - Группа товаров, которая содержит условие отбора только по разделу (источник тега `<categoryId>`), будет представлена в виде тега `<product>` с аттрибутом `category-id`;
    - Выгружается только предложения, которые присутствует в файле выгрузки в секции `<offers>`;
    - Подсчет количества товаров по фильтрам не учитывает: присутсвует ли предложение в файле выгрузке;
    - Список инфоблоков составляется на основании связанных «Профилей выгрузки»;
    - Если в инфоблоке отсутствует предложения по акции, то оставьте список групп товаров пустым.

#### Вид акции «Скидка по промокоду»

Используется «Базовые поля акции» и дополнительные:
1. Тип скидки - правило применения скидки к стоимости товара. Варианты значений: «Процент» или «Сумма». Будет выгружен в качестве аттрибута `unit` тега `<discount>`;
2. Валюта скидки - валюта, в которой будет предоставлена скидка. Доступен только для типа скидки — «Процент». Будет выгружен в качестве аттрибута `currency` тега `<discount>`;
3. Величина скидки - размер скидки, будет выгружен в качестве значения тега `<discount>`;
4. Промокод - текст промокода, будет выгружен в тег `<promo-code>`. Максимальная длина — 20 символов.

Пример тега:
```xml
<promo id="12" type="promo code">
    <start-date>2019-01-02 17:35:00</start-date>
    <end-date>2019-03-31 17:35:00</end-date>
    <description>Промокод на 100 рублей</description>
    <url>https://my.site/promo-100-rub/</url>
    <promo-code>PROMO100RUB</promo-code>
    <discount unit="currency" currency="RUR">100</discount>
    <purchase>
        <product offer-id="62"/>
        <product offer-id="63"/>
    </purchase>
</promo>
```

#### Вид акции «Специальная цена в определенный период»

Используется «Базовые поля акции» и дополнительные:
1. Тип скидки - правило применения скидки к стоимости товара. Варианты значений: «Процент» или «Сумма»;
2. Валюта скидки - валюта, в которой будет предоставлена скидка. Доступен только для типа скидки — «Процент»;
3. Величина скидки - размер скидки.

К каждому тегу `<product>` будет добавлен тег `<discount-price>`, указывающий цену товара по акции:
- Цена будет сформирована на основании значений полей «Тип скидки», «Валюта скидки», «Величина скидки» и «Цены товара без учета скидок»;
- Источником значения «Цена товара без учета скидок» будет использован один из источников тегов `<oldprice>` или `<price>` без учета скидок;
- Если «Валюта скидки» и значение тега `<currencyId>` отличаются, то скидка будет применена относительно значения тега `<currencyId>`, «Величина скидки» будет сконвертирована в соответствие с курсами валют, используемыми на сайте.

Пример тега:
```xml
<promo id="19" type="flash discount">
    <start-date>2019-01-02 17:35:00</start-date>
    <end-date>2019-03-31 17:35:00</end-date>
    <description>Февраль-Март 2019</description>
    <url>https://my.site/flash-february-march-2019/</url>
    <purchase>
        <product offer-id="44">
            <discount-price currency="RUR">900</discount-price>
        </product>
        <product offer-id="45">
            <discount-price currency="RUR">4500</discount-price>
        </product>
        <product offer-id="46">
            <discount-price currency="RUR">8100</discount-price>
        </product>
    </purchase>
</promo>
```

#### Вид акции «При покупке N товаров M таких же товаров бесплатно»

Используется «Базовые поля акции» и дополнительные:
1. Количество товаров, которое нужно приобрести, чтобы получить подарок - значение будет выгружено в тег `<required-quantity>`;
2. Количество товаров, которые покупатель получит в подарок - значение будет выгружено в тег `<free-quantity>`.

Пример тега:
```xml
<promo id="20" type="n plus m">
    <start-date>2019-01-02 17:35:00</start-date>
    <end-date>2019-03-31 17:35:00</end-date>
    <description>Купи 10 товаров, получи 5 в подарок</description>
    <url>https://my.site/10-plus-5/</url>
    <purchase>
        <required-quantity>10</required-quantity>
        <free-quantity>5</free-quantity>
        <product offer-id="44"/>
        <product offer-id="45"/>
        <product offer-id="46"/>
    </purchase>
</promo>
```

#### Вид акции «При покупке N товаров M таких же товаров бесплатно»

Используется «Базовые поля акции» и дополнительные:
1. Количество товаров, которое нужно приобрести, чтобы получить подарок - значение будет выгружено в тег `<required-quantity>`;
2. Подарки по акции - наборы групп товаров и торговых предложений, которые являются подарками по акции. Примечания:
    - Результат выгрузки - тег `<promo-gift>` для каждого подарка акции;
    - Инфоблок для подарков выбирается на шаге «Общие настройки».
3. Выгружать подарки, которые не попали в выгрузку - разрешает создавать теги `<gift>`, если подарок по акции отсутствует в секции `<offers>`. 

Пример тега:
```xml
<promo id="21" type="gift with purchase">
    <start-date>2019-01-02 17:35:00</start-date>
    <end-date>2019-03-31 17:35:00</end-date>
    <description>Подарок при покупке</description>
    <url>https://my.site/gift/</url>
    <purchase>
        <required-quantity>10</required-quantity>
        <product offer-id="102"/>
        <product offer-id="103"/>
    </purchase>
    <promo-gifts>
        <promo-gift offer-id="262"/>
        <promo-gift gift-id="263"/>
    </promo-gifts>
</promo>
```

Тег `<gift>` будет сформирован по следующим правилам:
1. Если инфоблоков подарков, используется в «Профиле выгрузки», то:
    - `<name>` - будет использовать источник значений тегов `<name>` или `<model>` «Профиля выгрузки»;
    - `<picture>` - будет использовать источник значения тега `<picture>` «Профиля выгрузки».
2. Если инфоблок подароков, не используется в «Профиле выгрузки», то:
    - `<name>` - «Название» элемента инфоблока;
    - `<picture>` - «Детальная картинка» или «Картинка для анонса» элемента инфоблока.
    
Если значение тегов `<name>` или `<picture>` не заполнено, то тег `<gift>` не будет выгружен.

```xml
<gift id="263">
    <name>Ремень Грубая Кожа 2</name>
    <picture>https://my.site/upload/iblock/1b4/1b461cadca701eea8c2cd52435521692.jpg</picture>
</gift>
```

#### Вид акции «Скидка модуля «Интернет-магазин»

Список полей:
1. Скидка - скидка модуля «Интернет-магазин».

Поддерживаем типы `<promo>`:
- promo code - скидка с купонами, первое действие которой «Изменить стоимость товаров в корзине».
    * Товары по акции выбираются на основании условий действий «Изменить стоимость товаров в корзине»; 
    * Будет выбран первый «Многоразовый купон», у которого отсутсвует привязка к пользователю и не превышено количество использований;
    * Если скидка содержит несколько действий, то для тега `<discount>` будет выбрано максимальное значение.
- flash discount - скидка без купонов, первое действие которой «Изменить стоимость товаров в корзине». 
    * Товары по акции выбираются на основании условий действий «Изменить стоимость товаров в корзине»; 
    * В скидке должны быть заполнены даты активности;
    * Для применения скидки к цене товара не используется API Битрикс, скидки не суммируются.
- gift with purchase - скидка, первое действие которой «Предоставить подарок». 
    * Товары по акции выбираются на основании условий «Товары» из секции «Дополнительные условия»;
    * Подарки по акции выбираются на основании условий «Товар» и «Раздел» действий «Предоставить подарок».

Примечания:
- Если скидка содержит несколько действий разных типов, то будут использованы только действия, тип которых соответсвует первому действию;
- Не учитывается значения «Прекратить применение скидок на текущем уровне приоритетов» и «Прекратить дальнейшее применение правил»;
- Действие «Изменить стоимость доставки» не выгружается;
- После внесения изменения в форме редактирования «Скидки модуля «Интернет-магазин», необходимо выполнить выгрузку связанного элемента «Промо».

#### Вид акции «Скидка модуля «Торговый каталог»

Список полей:
1. Скидка - скидка модуля «Торговый каталог».

Поддерживаем типы `<promo>`:
- promo code - скидка с купонами. 
    * Товары по акции выбираются на основании условий на вкладке «Условия»; 
    * Не поддерживается тип скидки «Установить цену на товар»;
    * Будет выбран первый «Многоразовый купон».
- flash discount - скидка без купонов. 
    * Товары по акции выбираются на основании условий на вкладке «Условия»; 
    * В скидке должны быть заполнены даты активности;
    * Для применения скидки к цене товара не используется API Битрикс, скидки не суммируются.

Примечания:
- Не учитывается значения «Прекратить дальнейшее применение скидок»;
- После внесения изменения в форме редактирования «Скидки модуля «Торговый каталог», необходимо выполнить выгрузку связанного элемента «Промо».

## Выгрузка Промо

С помощью формы «Выгрузка Промо» вы можете выгрузить теги `<promo>` в файлы «Профилей выгрузки».

Список полей:
1. Промо - список активных акций, выбранные значения которого будут добавлены/обновлены в файлы «Профилей выгрузки»;
2. Удалить неактивные - удалить теги `<promo>`, которые были ранее выгружены, но на текущий момент удалены или деактированы;
3. Длительность шага - время в секундах, которое может быть использовано для одного шага выгрузки;
4. Интервал - время в секундах между шагами выгрузки.

Для запуска выгрузки нажмите кнопку «Запустить выгрузки». По окончанию процесса выгрузки будут отображено сообщение «Выгрузка выполнена» или «Произошла ошибка». Если выгрузка прошла успешно, то будет отображена ссылка на страницу «Результаты выгрузки», где вы можете просмотреть «Содержимое тега» и «Журнал ошибок» для каждого «Профиля выгрузки» и «Промо».

Особенности выгрузки:
1. После редактирования «Промо», которая актуальна на текущий момент, необходимо на странице «Выгрузка промо» выполнить выгрузку, выбрав в поле «Промо» элемент, который необходимо обновить;
2. Если «Дата и время начала», указанная в форме редактирования «Промо», еще не наступила, то тег `<promo>` будет выгружен автоматически в момент начала акции (выполняется на агентах Битрикс);
3. Если «Дата и время завершения», указанная в форме редактирования «Промо», еще не наступила, то тег `<promo>` будет удален автоматически в момент завершения акции (выполняется на агентах Битрикс);
4. После деактивации «Промо», которая была ранее выгружена, необходимо на странице «Выгрузка промо» выполнить выгрузку, отметив чекбокс «Удалить неактивные».

Основные ошибки:
1. `Тег product: Пустое значение` - не найдены товары, которые выгружены в файл выгрузки и подпадают под условия «Товары по акции», указанные в форме редактирования «Промо»;
2. `Тег promo-gift: Пустое значение` или `Тег promo-gifts: Пустой тег` - не найдены подарки, которые подпадают под условия «Подарки по акции», указанные в форме редактирования «Промо»;
3. `Тег start-date: Пустое значение` или `Тег end-date: Пустое значение` - даты активности, являются обязательными для вида акции «Специальная цена в определенный период».
