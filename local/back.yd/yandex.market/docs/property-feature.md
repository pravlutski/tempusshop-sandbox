# Умные свойства

Источник, который позволяет выгружать наборы свойств инфоблока. Выбор свойств осуществляется с помощью механизма [«Единого управления свойствами»](https://dev.1c-bitrix.ru/learning/course/index.php?COURSE_ID=42&LESSON_ID=1986).

## Требования

* Версия модуля **Информационные блоки** не менее 18.5.4;
* В настройках модуля **Информационные блоки** включен флаг **Использовать параметры свойств в компонентах и формах**.

## Выбор свойств

Управление осуществляется с помощью формы **Редактирования свойства инфоблока**. Настройки, касаемые показа, сгруппированы в секции Параметры свойства:

![Параметры свойства](/docs/file/property-feature/parameters.png)

Модуля Яндекс.Маркет добавляет свои вариант парамеров:

* Умные свойства для Маркета и Беру - выгружать в прайс-листах Маркета и Беру;
* Умные свойства для Турбо-страниц - выгружать в прайс-листах Турбо-страниц.

Открыть форму можно двумя способами:

* Способ №1:
    * Откройте форму редактирования инфоблока (Контент > Инфоблоки > Типы инфоблоков > <название_вашего_типа> > <название_вашего_инфоблока>) и перейдите на закладку Свойства.
    * В строке интересующего вас свойства нажмите кнопку [...].
* Способ №2:
    * Откройте страницу со списком инфоблоков (Контент > Инфоблоки > Типы инфоблоков > <название_вашего_типа>).
    * В строке вашего инфоблока нажмите пункт Свойства в меню действий. Откроется страница со списком свойств.
    * Для нового свойства нажмите кнопку Добавить свойство, для уже существующего - пункт Изменить в меню действий.

## Использование в прайс-листе

На шаге Сопоставление полей в форме редактирования Прайс-листа выберите:
* тег `<param>`: источник - Умные свойства, поле - значения набора свойств (например: Значения «На детальной странице»);
* атрибут `name=`: источник - Умные свойства, поле - названия набора свойств (например: Названия «На детальной странице»);
* атрибут `unit=`: источник - Умные свойства, поле - единица измерения набора свойств (например: Единица измерения «На детальной странице»).

Соответствие параметров свойств и наборов для выгрузки:

Параметр свойства | Набор для выгрузки
------------ | -------------
Показывать на странице списка элементов | В списке
Показывать на детальной странице элемента | На детальной странице
Значение добавляется в корзину | В корзине
Используется для выбора торговых предложений | Выбор предложения
Умные свойства для Маркета и Беру | Маркет и Беру
Умные свойства для Турбо-страниц | Турбо-страницы
